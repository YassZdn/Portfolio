Projet principal : infrastructure d'entreprise virtualisée

Réalisé dans le cadre de la formation BTS SIO option SISR. Une maquette d'infrastructure de PME montée sur du matériel physique, du câblage jusqu'à la création automatique des tickets d'incident.

Un système d'information complet sur deux postes physiques

J'ai déployé un hyperviseur Proxmox VE sur un Lenovo ThinkCentre M73 (passé à 16 Go de RAM), relié à un routeur TP-Link ER605 et à un switch manageable. Trois machines virtuelles réparties sur deux VLAN reproduisent un réseau d'entreprise : un serveur Linux de services, un contrôleur de domaine Windows et un poste client.

Les trois briques d'administration (annuaire, gestion de parc, supervision) sont reliées entre elles : une alerte Zabbix ouvre un ticket GLPI, et un seul script PowerShell crée un utilisateur partout à la fois.

Problèmes rencontrés et résolus

VLAN entre les VM

Les machines ne communiquaient pas d'un VLAN à l'autre. J'ai activé la gestion des VLAN sur le pont réseau de Proxmox et configuré les ports du switch en conséquence.

VMware sous Linux

VMware n'était pas compatible avec le noyau installé. Je suis revenu à une version antérieure du noyau, puis j'ai déplacé le poste client sur Proxmox pour fiabiliser les VLAN.

Installation de GLPI

La version de PHP n'était pas supportée. J'ai installé PHP 8.3, corrigé la configuration d'Apache et sécurisé les cookies de session.

Scripts et HTTPS

PowerShell refusait les certificats auto-signés de mes serveurs. J'ai adapté le script pour qu'il puisse appeler les API en HTTPS.
